# Apple App Store Privacy Nutrition Label — Istikhara (`com.istikhara.app`)

Use these exact responses in App Store Connect → **App Privacy**.

## Does this app collect data?
**Yes** — solely through the **Google Mobile Ads (AdMob) SDK** when ads are served (never from Quran reading, Dua, Intention notes, or exports).

## Data Linked to the User
- **None** (the app has no user accounts, login, or backend database).

## Data Used to Track You
*(Only if the user taps "Allow" on the iOS App Tracking Transparency prompt)*:
- **Identifiers** → **Device ID** (IDFA) — Purpose: *Third-Party Advertising*.

## Data Not Linked to You
| Data Type | Purpose |
|---|---|
| **Identifiers** (Device ID / IDFV) | Third-Party Advertising, Analytics, Fraud Prevention |
| **Usage Data** (Advertising Data — ad impressions & interactions) | Third-Party Advertising, Analytics |
| **Diagnostics** (Crash Data, Performance Data) | App Functionality, Analytics |
| **Location** (Coarse Location, IP-derived) | Third-Party Advertising |

`https://istikhara-quran-app.netlify.app/en/privacy` (and `/ur/privacy` for Urdu).
