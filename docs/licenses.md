## Quran Text, Translations & Tafseer

- **Al-Quran Cloud (`api.alquran.cloud`)**: `quran-uthmani`, `ur.jalandhry` (Fateh Muhammad Jalandhry), `en.sahih` (Saheeh International).
- **Quran.com / QUL (`api.quran.com` / `qul.tarteel.ai`)**: `qpc-hafs` (`text_uthmani`), `qul-indopak` (`text_indopak`), and word-by-word Urdu meanings (`لفظی ترجمہ`).
- **Urdu Tafseer**: Authentic published Urdu tafseer sources (Tafsir Ibn Kathir Urdu / Maarif-ul-Quran / Bayan-ul-Quran) via verified endpoints with full source attribution.

## Audio Recitations & Word Timings

- **EveryAyah / Al-Quran Cloud / QUL**: Recitations by Mishary Rashid Alafasy, Abdul Basit (Murattal), and Mahmoud Khalil Al-Husary.
- **Word-Level Timing Data**: QUL recitation segment data / open `quran-align` dataset (MIT / CC-BY), paired strictly with the matching EveryAyah recording edition.
